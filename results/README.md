# Simulation output

These files are generated by the four Python scripts in `src/` and committed from a clean GitHub Actions run.

| Experiment | CSV output | Plots |
| --- | --- | --- |
| Baseline | `baseline_bus_voltages.csv` | `baseline_bus_voltages.png` |
| Load growth | `load_growth_results.csv`, `load_growth_bus_voltages.csv` | `minimum_voltage_vs_demand.png`, `undervoltage_buses_vs_demand.png`, `load_growth_voltage_profiles.png` |
| Solar at Bus 18 | `solar_integration_results.csv`, `solar_bus_voltages.csv` | `solar_line_losses_regenerated.png`, `solar_voltage_limits_regenerated.png`, `solar_voltage_profiles_regenerated.png` |
| Solar placement (128 cases) | `solar_placement_results.csv` | `solar_placement_comparison.png` |

The `*_terminal_output.txt` files also contain the printed results from each script.

The original schematic is in `figures/ieee33_bus_topology.png`. Use the generated **PNG charts and CSV tables** for measured simulation output; the older SVG summary sketches have been retired.

To regenerate the outputs locally from the repository root:

```bash
python -m pip install -r requirements.txt
python src/baseline.py
python src/load_growth_analysis.py
python src/solar_integration.py
python src/solar_optimization.py
```

The placement output contains all four capacities at each bus from 2 to 33. The best-case selection is based on **losses only**; no 128-case result satisfies the 0.95–1.05 p.u. voltage-reference band.
